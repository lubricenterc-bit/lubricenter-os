# Switzer

Tipografía Switzer de Indian Type Foundry, distribuida por Fontshare bajo la ITF Free Font License, que permite uso personal y comercial. Archivos WOFF2 latinos en los pesos 400, 500, 600, 700 y 800, tomados del paquete npm `@carrot-kpi/switzer-font` 0.1.0.

Antes de redistribuir los archivos fuera de esta aplicación, revisa la licencia vigente en https://www.fontshare.com/fonts/switzer.
